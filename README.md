# Sharaan's AI+ Studio Workshop Website

## Live website

[Visit Sharaan’s AI+ Studio](https://gitty-hash.github.io/AI-Studio-Website-Sharaan/)

A responsive workshop showcase with University of Arizona Libraries visual branding, workshop search and category filters, and interactive topic previews.

The Intro to Gemini Notebook workshop links to https://github.com/gitty-hash/Intro-to-Gemini-Notebook.

## Files

- `index.html`: page content and structure
- `style.css`: styling and responsive layouts
- `app.js`: search, filters, and topic tabs
- `assets/libraries-logo.svg`: University of Arizona Libraries logo

## Preview

Open `index.html` in a browser, or serve this directory with any static HTTP server. Google Fonts requires an internet connection; local fallback fonts are included in the stylesheet.

This is a static site and requires no build step. It can be hosted from the repository root with GitHub Pages.

The Libraries logo is sourced from https://lib.arizona.edu/logo.svg. This workshop showcase uses the University Libraries visual identity as requested; the branding does not imply institutional endorsement.
